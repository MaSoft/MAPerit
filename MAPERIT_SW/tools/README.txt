MaPeriT.SW - Herramientas Externas
====================================

Esta carpeta incluye WinPmem (winpmem_mini_x64.exe, licencia Apache 2.0),
que MaPeriT.SW usa para el volcado de memoria RAM. Se detecta
automaticamente al ejecutarse; si se elimina, el volcado de RAM se omite
con un aviso.

Version original y actualizaciones:
  https://github.com/Velocidex/WinPmem/releases
